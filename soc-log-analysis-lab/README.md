# SOC Log Analysis Lab

This project demonstrates how security analysts monitor and analyze system logs to detect suspicious activity.

Security Operations Centers (SOC) rely on log analysis to identify potential threats and respond to incidents.

## Technologies Used

- Splunk
- Wireshark
- Linux system logs
- Windows event logs

## Security Concepts

- Security monitoring
- Log analysis
- Threat detection
- Incident response

## Project Goals

- Collect logs from systems and applications
- Analyze logs for suspicious activity
- Identify indicators of compromise
- Document security events

## Example Threat Scenarios

### Brute Force Login Attempts

Multiple failed login attempts detected within a short time period.

### Suspicious Network Traffic

Unexpected network connections or abnormal traffic patterns.

### Unauthorized Access Attempts

Access attempts from unknown or unauthorized users.

## Outcome

This project demonstrates the ability to analyze logs and identify potential security incidents.

Log analysis is a critical skill for cybersecurity analysts working in security operations environments.
