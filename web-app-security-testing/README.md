# Web Application Security Testing Lab

This project demonstrates how to identify and analyze common web application vulnerabilities.

The lab uses intentionally vulnerable applications to practice discovering and documenting security flaws.

## Technologies Used

- OWASP Juice Shop
- Burp Suite
- Kali Linux
- Web browser developer tools

## Security Concepts

- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Authentication
- Insecure Direct Object Reference
- Input Validation

## Project Goals

- Learn how attackers exploit web applications
- Identify vulnerabilities using security testing tools
- Document vulnerabilities and explain their impact
- Understand mitigation techniques

## Example Vulnerabilities Tested

### SQL Injection

Attackers inject malicious SQL queries into application input fields to bypass authentication or access unauthorized data.

### Cross-Site Scripting (XSS)

Malicious scripts are injected into a trusted website and executed in a user's browser.

### Broken Authentication

Weak authentication systems may allow attackers to bypass login mechanisms.

## Outcome

This project demonstrates hands-on experience with web application security testing and vulnerability identification.

Understanding these vulnerabilities helps developers and security professionals build more secure applications.
