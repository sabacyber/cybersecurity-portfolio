# Cybersecurity Portfolio

This repository contains hands-on cybersecurity labs demonstrating practical skills across multiple security domains including application security, cloud security, DevSecOps, and security operations (SOC).

Each project focuses on real-world security concepts such as vulnerability detection, cloud monitoring, automated security pipelines, and log analysis.

## Portfolio Coverage

This portfolio demonstrates hands-on experience across several key cybersecurity domains:

```
Application Security
        ↓
Cloud Security Monitoring
        ↓
DevSecOps Security Automation
        ↓
Security Operations (SOC) Log Analysis
```


## Projects

### Web Application Security Testing Lab

Hands-on testing of common web application vulnerabilities using an intentionally vulnerable application.

Key concepts demonstrated:

- SQL Injection
- Cross-Site Scripting (XSS)
- Authentication request interception
- JWT token analysis

➡️ [View Project](web-app-security-testing)

---

### AWS Cloud Security Monitoring Lab

Monitoring AWS administrative activity using native cloud security services.

Key concepts demonstrated:

- AWS CloudTrail logging
- EventBridge security detection rules
- CloudWatch log monitoring
- IAM activity tracking

➡️ [View Project](aws-cloud-security-lab)

---

### DevSecOps Security Pipeline

Automated security testing integrated into a CI/CD pipeline using GitHub Actions.

Security scans include:

- Bandit static code analysis
- Trivy container vulnerability scanning
- Docker image builds

➡️ [View Project](devsecops-pipeline-project)

---

### SOC Log Analysis Lab

Simulated Security Operations Center investigation using authentication log analysis.

Key concepts demonstrated:

- brute-force login detection
- Python-based threat detection
- authentication log monitoring

➡️ [View Project](soc-log-analysis-lab)
